## 3. The "Pain" Log (CRITICAL)
* **Tried:** `React.createElement(InvoicePDF, { data })` passed directly to `renderToBuffer()`
* **Failed:** TypeScript error: `FunctionComponentElement` not assignable to `ReactElement<DocumentProps>`
* **Workaround:** Cast element as `any` before passing to `renderToBuffer()` — the component returns a valid `<Document>` at runtime

* **Tried:** Passing Node.js `Buffer` directly to `new NextResponse(buffer, ...)`
* **Failed:** TypeScript error: `Buffer` not assignable to `BodyInit | null | undefined`
* **Workaround:** Wrap with `new Uint8Array(buffer)` before passing to NextResponse

* **Tried:** Using `Record<string, unknown>` as type for audit meta field
* **Failed:** TypeScript error: not assignable to `JsonNull | InputJsonValue | undefined`
* **Workaround:** Import `Prisma` from `@prisma/client` and use `Prisma.InputJsonValue` type
